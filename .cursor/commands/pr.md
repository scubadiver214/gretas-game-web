Your job is to create a PR with a descriptive title. The title should be in the format of the branch name (number only) - remove the prefix being either "story/" or "bug/". As an example, a branch could be "story/421539" but the PR title would be "421539 - my pr title and description". Always use the github cli. if you haven't made a commit already, do that first using the same format at the PR title.
