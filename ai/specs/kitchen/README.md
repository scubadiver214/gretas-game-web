`/play/kitchen`. Code: `src/features/kitchen/`.

**Status:** playable.

## Original brief

Re-create and re-imagine this game as a fast-paced pizza cooking game set during a busy lunch rush. Customers order different pizzas with specific dough, sauce, cheese, and topping combinations, and the player must prep, assemble, bake, slice, and serve each order before the patience meter runs out. Include a shop system to unlock new ingredients, combo scoring, order difficulty progression, clear feedback for right and wrong toppings, and co-op or single-player station mechanics inspired by Overcooked.
